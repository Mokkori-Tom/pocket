# pocket をスマホで試す手順

pocket は、Android のホーム画面からワンタップで使える小さな道具のセットです。
入れると、ホーム画面に次のボタンが並びます。

| ボタン | 何ができるか |
|---|---|
| **クイックメモ** | 入力欄が出るので、思いついたことを書くと日時つきで保存されます。いつものキーボード（Gboard など）がそのまま使えます |
| **メモを見る** | 最近のメモ 10 件を表示します |
| **クリップを解読** | コピーした暗号のような文字列（`1763100000` や `44GT44KT44Gr44Gh44Gv` など）を読める形にします |
| **共有 → Termux** | ブラウザで見ているページを共有ボタンから送ると、「タイトル＋URL」の形でコピーされます |

所要時間は 10〜15 分くらいです。Android 専用です（iPhone では動きません）。

---

## 1. アプリを 3 つ入れる

アプリは **F-Droid** というアプリストアから入れます（Google Play ではありません）。

1. ブラウザで https://f-droid.org を開き、F-Droid アプリを入れます
   （「提供元不明のアプリ」を許可するよう求められたら許可します）
2. F-Droid で次の 3 つを入れます。
   - **Termux** … https://f-droid.org/packages/com.termux
   - **Termux:Widget** … https://f-droid.org/packages/com.termux.widget
   - **Termux:API** … https://f-droid.org/packages/com.termux.api

> ⚠️ **3 つとも F-Droid から入れてください。**
> Google Play 版の Termux がすでに入っている場合は、先にアンインストールしてください。
> 入手元が混ざると、ボタンを押しても動きません。

## 2. Termux でセットアップする

1. **Termux** を開きます（黒い画面が出ます。初回は準備に少し時間がかかります）
2. 下の 1 行を**コピー**します。

   ```
   pkg install -y git && git clone https://github.com/Mokkori-Tom/pocket && pocket/setup.sh
   ```

3. Termux の黒い画面を**長押し → 「Paste（貼り付け）」**して、キーボードの Enter を押します。
   （手で打つ必要はありません。Termux の画面では日本語や長い文の入力がしにくいので、貼り付けがおすすめです）
4. 途中で「ファイルへのアクセスを許可しますか」と聞かれたら **許可** を押します。
5. 最後に「**完了！**」と出れば成功です。

途中で `[Y/n]` などと聞かれて止まった場合は、Enter を押せば進みます。

## 3. 許可を 1 つ出す

**設定 → アプリ → Termux → 「他のアプリの上に重ねて表示」→ 許可**

- 機種によって「フローティング表示」「ポップアップ表示」「他のアプリの上に表示」などの名前です。
  見つからなければ、設定の検索で「重ねて」と入れてください。
- Xiaomi（Redmi / POCO）は、同じ画面の「バックグラウンドでポップアップウィンドウを表示」も許可してください。

## 4. ホーム画面にボタンを置く

1. ホーム画面の何もないところを**長押し → ウィジェット**
2. **Termux:Widget** を探してホーム画面に置きます
   - 一覧の形で置くタイプと、ボタンを 1 個ずつ置くタイプがあります。好きなほうでどうぞ

これで完了です。

---

## 使い方のコツ

- **クイックメモ**は入力欄が出るだけで、黒い画面は開きません。
- **メモを見る**・**クリップを解読**は、一瞬 Termux の黒い画面が開きます（Android の決まりで、コピーした内容を読むには画面の前に出る必要があるためです）。
  表示を読んだら **Enter** で閉じます。そのあと Termux の画面が残っていたら、ホームボタンで戻って大丈夫です。
- **共有 → Termux** は、ブラウザの共有ボタン → Termux を選びます。通知に「リンクをコピーしました」と出たら、メモアプリなどに貼り付けられます。
- メモは、スマホの「Documents」フォルダの `pocket-memo.md` に保存されます。ファイルアプリからも開けます。

## うまくいかないとき

| 出てきたもの | 原因と直し方 |
|---|---|
| `Termux requires "Display over other apps" permission ...` | 手順 3 の許可がまだです |
| `FileUtils Error: The executable regular file not found at path ...` | ボタンが古い場所を覚えています。ウィジェットの 🔄 を押すか、置き直してください（更新したあとによく起きます） |
| `command not found` | セットアップが途中で止まっています。手順 2 の 1 行をもう一度実行してください |
| クリップを解読で「空です」「読み取れませんでした」 | 先に何かをコピーしてからボタンを押してください |
| ボタンを押しても何も起きない | Termux:API が入っていないか、3 つのアプリの入手元が違います。手順 1 を確認してください |
| セットアップの最後に「Termux:API アプリから応答がありません」 | 同上 |

それでも動かないときは、画面のスクリーンショットを送ってください。

## 更新するとき

Termux を開いて、次の 1 行を貼り付けて Enter。

```
cd ~/pocket && git pull && ./setup.sh
```

更新後は、ウィジェットの 🔄 を押す（または置き直す）のを忘れずに。

## やめるとき

Termux・Termux:Widget・Termux:API の 3 つをアンインストールすれば、すべて消えます。
メモ（Documents の `pocket-memo.md`）だけはスマホに残ります。
